---
name: Photo metadata boundaries
description: How to handle the separate Gallery photo records versus authoritative project-photo metadata.
---

Gallery records are a separate content set from the workbook-backed project-detail photographs. When a legacy Gallery record cannot be verified against the authoritative project mapping, describe only what the image clearly shows and avoid inferred employer, vehicle model, equipment brand, date, or location claims.

**Why:** The project-detail workbook is authoritative for approved covers, roles, captions, and alt text; reusing or enriching older Gallery assertions can create contradictions, especially around charger hardware.

**How to apply:** Preserve the Gallery dataset and its filters, but reconcile any overlapping project claim against the authoritative mapping and use neutral captions/alt text when the source does not verify the detail.
